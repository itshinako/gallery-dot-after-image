# GALLERY DOT「AFTER IMAGE」LP
- ビルド不要の静的サイト。`index.html` を開く／GitHub Pages に `gallery-dot-after-image/` 直下を公開。GASは公開しない（`gas/` は除外可）。
- 設定は `config.js`。`GAS_WEB_APP_URL` が空の間は**デモモード**（予約は確定しません）。
- 予約はGAS経由でGoogle Sheetsの `reservations` シートに保存。設定・デプロイ手順は `gas/README.md`。
- canonical URL、SEO description、OGP/Twitterカード（画像は `images/gallery.webp`）は `https://gallery-dot.jp/` に設定済み。SNS・LINE URL、GA4 IDは公開前に設定。予約完了画面にもLINE友だち追加を案内するため、`config.js` の `LINE_URL` を設定。
